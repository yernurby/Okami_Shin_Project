> *«Слабые уходят в страхе. Сильные — с достоинством.»*

## О проекте

**Жанр:** Вебтун | Школьная драма + Улица + Романтика + Боевик
**Формат:** Вертикальный скролл, 1 глава = 5–20 страниц текста
**Объём:** ~150–200 глав + эпилог
**Атмосфера:** Токийские мстители × Классная комната превосходства — с живым сердцем

### Синопсис

16-летний Шин Оками переезжает в Токио с мамой и маленькой сестрой. Снаружи — бандит с татуировками и звериным взглядом. Внутри — человек который всю жизнь защищал семью и не умел доверять никому кроме них.

В элитной школе Кайсей его принудительно записывают в баскетбольную секцию. Через уличного игрока впервые находит что-то своё. Параллельно — ищет правду об отце, погибшем два года назад.

**Три главные линии:**
- 🧩 **Мозаика Кэндзи** — правда об отце собирается по кускам
- 🏀 **Команда** — Шин находит людей которые становятся своими
- ❤️ **Рэй** — единственная без связи с судьбой. Просто выбрала сама.

**Посыл:** Кем кажешься vs кто ты есть → одиночество разрушает стену → прошлое не определяет
