# Фоновая музыка

Плеер уже встроен в сайт. Кнопка **♪** появляется в шапке **только если в плейлисте есть хотя бы один трек** — пока список пуст, читатель её не видит и ничего лишнего на странице нет.

## Как добавить музыку

1. Положить аудиофайл в эту папку: `assets/music/`
2. Прописать его в `data/music.json`:

```json
{
  "tracks": [
    { "title": "Дождь над Итабаси", "file": "assets/music/rain.mp3", "loop": true }
  ]
}
```

`index.html` при этом трогать не нужно — ровно как с `data/chapters.json`.

## Поля трека

| Поле | Обязательно | Что делает |
|---|---|---|
| `file` | да | путь от корня сайта |
| `title` | нет | подпись в панели; если не указать — возьмётся имя файла |
| `loop` | нет | `true` — трек повторяется бесшовно, без стыка и без паузы |

## ⭐ Как сделать «непрерывную, очень долгую» музыку

**Не длинным файлом, а лупом.** Часовой mp3 весит ~50 МБ, грузится на телефоне минуту и жрёт трафик читателя. Вместо этого:

- берётся **зацикленный отрывок на 2–4 минуты** (ambient, lo-fi, дождь, город);
- ставится `"loop": true`;
- играет **бесконечно**, пока читатель не выключит.

При `loop: true` браузер повторяет трек средствами самого аудиодвижка — стыка не слышно вообще, паузы между повторами нет. Если в плейлисте **всего один трек**, `loop` включается автоматически, даже без поля.

Несколько треков без `loop` играют по кругу друг за другом (после последнего — снова первый), но между ними будет короткая пауза на подгрузку.

## Формат и размер

- **mp3** — берут все браузеры, это самый безопасный выбор. `.m4a`/`.aac` тоже. `.ogg` не играет в Safari.
- **96–128 kbps** для фона более чем достаточно: это фон, а не концерт. Примерно **1 МБ на минуту**.
- Ориентир: 3-минутный луп на 128 kbps ≈ **3 МБ**. Это нормально для репозитория.
- Держать общий вес музыки в пределах ~30–50 МБ: GitHub Pages отдаёт сайт целиком, и каждый лишний мегабайт — это трафик читателя с телефона.

## ⚠️ Права

Файлы лежат в публичном репозитории и раздаются с сайта — это **распространение**, а не «послушать у себя». Поэтому нельзя просто взять OST из аниме или трек с ютуба.

Что можно:
- музыка под **CC0 / CC-BY** (при CC-BY указать автора — можно в подвале сайта или в `title`);
- **royalty-free** библиотеки с лицензией, разрешающей веб-публикацию;
- **своё** или написанное знакомым композитором с разрешением.

## Что плеер делает сам

- **Не прерывается при переходе между главами** — сайт SPA на hash-роутинге, страница не перезагружается.
- **Выключен по умолчанию**, громкость стартует на 25%.
- Помнит трек, позицию и громкость в `localStorage`.
- При настоящей перезагрузке (F5, открытие ссылки в новой вкладке) позиция восстанавливается, **но звук сам не включится** — браузеры запрещают автозапуск со звуком без клика. Плеер это честно пишет в подсказке: «Нажмите ▶».
